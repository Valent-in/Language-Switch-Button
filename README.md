# Language-Switch-Button

Extension for Gnome Shell

Switch input language with a single click!  
Also makes language indicator uppercase.

Install: [extensions.gnome.org](https://extensions.gnome.org/extension/7102/language-switch-button)

Created as "temporary" fix for GS bug [GitLab - issue #6484](https://gitlab.gnome.org/GNOME/gnome-shell/-/issues/6484)
